#### 🔧 What I'm working on

**[TaskGraph](https://github.com/QiuYilin/taskgraph)** — a C++17 dataflow graph framework built on [taskflow](https://github.com/taskflow/taskflow), with optional ImGui and Qt workbenches. Every operator is a typed node, every edge is a binding, and the whole pipeline can be edited and run as a graph.

**[PCLgraph](https://github.com/QiuYilin/PCLgraph)** — a 3D vision dataflow framework built on [PCL](https://pointclouds.org/) and TaskGraph: every PCL algorithm is a typed node, point clouds travel between nodes, and a full registration pipeline can be wired, inspected and run in the workbench.

**[vcpkg-registry](https://github.com/QiuYilin/vcpkg-registry)** — a personal vcpkg registry that keeps my C++ builds reproducible across machines.
